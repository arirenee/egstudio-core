# EG Studio Staging

Staging repository for EG Studio development, testing, and validation before production deployment.

This repository is not the live website. The production source is [egstudio-v2](https://github.com/arirenee/egstudio-v2), which powers [egstudio.tech](https://egstudio.tech/).

## Repository roles

- **Production:** [egstudio-v2](https://github.com/arirenee/egstudio-v2) — live website.
- **Staging:** [egstudio-core](https://github.com/arirenee/egstudio-core) — development and validation.
- **Archive:** [egstudio-homepage](https://github.com/arirenee/egstudio-homepage) — historical homepage experiments and conversion tests.

## Historical design material

The [Homepage Conversion System V1](docs/HOMEPAGE_DX_V1.md) is an earlier design brief kept for reference. It does not define the current production offer, prices, or checkout flow.
